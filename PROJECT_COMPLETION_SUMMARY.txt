MATHEMATICAL FORMULAS IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════

Execution Time:
  T_exec = (instructions / allocatedMips) × 1000  [milliseconds]

Transfer Time:
  T_trans = [(taskSizeMB × 8) / bandwidthMbps] × 1000  [milliseconds]

Total End-to-End Latency:
  T_total = T_exec + T_trans + T_prop  [milliseconds]

Propagation Delay:
  Cloud:     80 ms (WAN)
  RSU:       10 ms (LTE/5G)
  Vehicle:   1 ms (local)

CPU Utilization:
  U_cpu = UsedMIPS / TotalMIPS  ∈ [0, 1]

RAM Utilization:
  U_ram = UsedRAM / TotalRAM  ∈ [0, 1]

Health Score:
  H(n) = 1 - (α·U_cpu + β·U_ram)  where α=0.6, β=0.4

TOPSIS Closeness Coefficient:
  C_i = S_i⁻ / (S_i⁺ + S_i⁻)  ∈ [0, 1]
